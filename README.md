## ✦ About the Project

**moityyy** is my personal interactive portfolio — a digital space that brings together my work, interests, experiments, and creative identity.

Rather than following the conventional developer portfolio layout, I wanted to build something that feels more personal: an experience inspired by retro scrapbook aesthetics, pixel art, playful visual elements, and a warm cream-and-dusty-pink palette.

The idea is simple: a portfolio should not only tell people what you can do. It should give them a glimpse of how you think, what inspires you, and what you enjoy creating.

This project is an ongoing expression of that idea.

## 🎨 Design Philosophy

The visual direction draws inspiration from:

- **Retro scrapbook aesthetics** — a collection of thoughts, memories, and creative fragments.
- **Pixel art** — nostalgic digital elements and playful interactions.
- **Editorial layouts** — expressive typography and intentional visual hierarchy.
- **Soft colour palettes** — cream, dusty pink, and complementary muted tones.
- **Motion and interaction** — animations that make the experience feel alive without overwhelming the content.

The goal was to create a digital identity that feels expressive, unconventional, and distinctly personal.

## ✨ Highlights

- **Personal visual identity:** A portfolio designed around the moityyy identity.
- **Interactive experience:** Visual details and motion that make exploring the website engaging.
- **Creative presentation:** A design-led approach to presenting personal work and interests.
- **Responsive design:** Intended to provide a comfortable browsing experience across screen sizes.
- **Personal storytelling:** A portfolio that communicates more than just technical skills.

## 🚀 Getting Started

To explore the project locally:

### 1. Clone the repository

```bash
git clone https://github.com/mxhxt010-code/InteractivePortfolio.git
```

### 2. Navigate to the project directory

```bash
cd InteractivePortfolio
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL printed in your terminal.

> These commands assume the project uses npm and provides a `dev` script in `package.json`.
